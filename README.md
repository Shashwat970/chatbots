# 🤖 Shake's Chatbot Collection

Welcome to **Shake's Chatbots** – a curated set of intelligent assistants built with Python, specializing in the fields of:

- 🛡️ **Cybersecurity**
- 📊 **Data Science**
- 🧠 **Artificial Intelligence**
- 🧬 **Deep Learning**

Each bot is tailored to serve specific purposes, from automating data analysis to simulating security response protocols and holding intelligent conversations.

---

## 🔧 Technologies Used

- **Primary Language**: Python
- **Frameworks & Libraries**:
  - `TensorFlow`, `PyTorch` – Deep Learning
  - `scikit-learn`, `pandas`, `NumPy` – Data Science
  - `transformers`, `spaCy`, `NLTK` – Natural Language Processing
  - `Flask` / `FastAPI` – API integration
  - `OpenAI API`, `LangChain`, `Hugging Face` – AI & LLM integration

---

## 🤖 Featured Bots

### 1. **CyberGuard**
- Role: Monitors logs, detects threats, explains vulnerabilities.
- Tech: Python, Regex, NLTK, Flask
- Features:
  - Real-time log analysis
  - Threat classification using NLP
  - Common vulnerability explanations (e.g., SQLi, XSS)

---

### 2. **DataMentor**
- Role: Assists with data exploration and preprocessing.
- Tech: Python, pandas, matplotlib
- Features:
  - CSV/Excel parsing
  - Data cleaning recommendations
  - EDA insights with charts

---

### 3. **NeuroChat**
- Role: Deep learning conversational AI
- Tech: PyTorch, transformers
- Features:
  - GPT-based fine-tuned chatbot
  - Context-aware responses
  - Supports multilingual interactions

---

### 4. **InsightBot**
- Role: Data science assistant for model training and evaluation
- Tech: scikit-learn, seaborn
- Features:
  - Model suggestions
  - Confusion matrix & accuracy reporting
  - Feature importance analysis

---

### 5. **SecuQ&A**
- Role: Cybersecurity query responder
- Tech: LangChain, custom knowledge base
- Features:
  - Security-focused Q&A
  - Threat examples
  - Real-world use cases for awareness
